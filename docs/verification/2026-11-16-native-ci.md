## Limits

This is native automated test acceptance with sandbox HOME, dummy keys and fake provider/hook fixtures, not a live installation using real service credentials. The interactive scratch-project acceptance remains c1. Live slash invocation, real-history retrieval and general model reliability are not established by these tests. Tuning has a separately performed input-only synthetic smoke test, not a performance benchmark.

The logs identify the macOS job shell as `/bin/bash` and the Windows shell as Git for Windows' `bash.EXE`; they do not print shell versions. No separate Bash 3.2 version probe is claimed. Standalone skilletor/briefing runtime support remains c9 and is not inferred from this result.
